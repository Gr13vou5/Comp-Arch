## How To Run

### 1. Place MARS Jar File
Ensure that the Mars4_5.jar file is located in the root directory of the project.

### 2. Add Testcases
All test files must be placed inside the Testcases/ folder.

#### desired.txt
Contains the desired signal values.

#### input_X.txt
Contains the input signals for a specific test case.

#### expected_X.txt
Contains the expected program output.

### 3. Execution
Run: python Tester.py
